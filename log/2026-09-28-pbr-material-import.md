# 场地外围 PBR 材质导入探索

## 目标与结果

建立可复用的材质导入规范，以一套真实扫描地表材质验证从资源准备到场景显示的完整流程。当前只替换场地边界之外的地面；房屋和院子的材质保持原样。

## 已完成

- 引入 Poly Haven 的 Leafy Grass（Charlotte Baglioni，CC0），记录来源、授权、日期与源文件 SHA-256。
- 确认材质真实覆盖 2 × 2 m；准备 Base Color、OpenGL Normal 和 ORM 三张配准贴图。
- 新增 Python 导入器，源文件缓存在非公开目录，生成本地 1K/2K WebP 包和运行时清单。
- 新增独立 `src/materials/` 模块，统一颜色空间、法线约定、ORM 通道、物理比例、取消加载和资源释放。
- 外围几何使用四块矩形围出场地空洞，UV 固定在世界米制坐标，场地变化不会拉伸或平移纹理。
- 地形专用采样混合不同偏移，减轻大面积重复；颜色、法线和 ORM 保持相同偏移。细节会略有柔化，采样成本也增加。
- 加载失败或超时保留原有中性地面；原始大图与第三方 API 不进入运行时请求。

## 性能取舍

默认 1K：4.11 MiB 下载、约 16 MiB GPU 纹理（含 mipmaps）。可选 2K：17.13 MiB、约 64 MiB。GPU 估算不含解码图片、阴影及其他场景资源。WebP 是传输压缩，不是 GPU 压缩。

## 验证与边界

新增测试覆盖清单错误、通道映射、物理比例、外围区域、UV 固定与部分下载失败/取消后的资源释放。素材检查命令验证文件字节数和 SHA-256。实景使用浏览器检查。

本轮是材质导入原型，不是完成的照片级环境。平面扫描材质不能提供草叶轮廓、地形起伏或近距离几何细节；移动设备性能和独立 WebGPU 验证仍待后续研究。

## 使用

```sh
npm run materials:import -- materials/sources/leafy-grass.json
npm run materials:check
```

完整规范、目录结构、贴图约定、预算与下一步研究见 [材质导入流程](../docs/materials/import-workflow.md)。

最终验证：18 项测试通过；素材清单及文件校验、TypeScript、ESLint 和生产构建通过。浏览器检查了实际着色器编译、零值与非对称场地边界，未出现新的控制台错误。已有构建包体积提示仍保留。
